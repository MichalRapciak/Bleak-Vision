HOW TO PLAY THE GAME:
-Use WASD keys to move
-Use Space Key to do a spin/dodge
-Use Left Shift to sprint
-Use your mouse to aim
-Use Mouse Button (either) to shoot
-During game, press Esc to pause the game and access the upgrades menu

(If you want to see and access the player/map transformation more easily, you can press H to cheat yourself Souls and
use them on upgrades in the devil/angel directions to see the player and map transforming)

Notes: The project is fully linked statically, which means you only need the ASSETS folder and the .exe to run it.
If interested, you can read my CODING DIARY.txt to see what I worked on day-by-day, I wrote down some of the issues
I was facing along the way too.
